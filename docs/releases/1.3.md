Floggfy 1.3 adds support for the Spotify 1.3.9 desktop update (tested with
1.3.9.2055 on Windows x64).

- Improved song recording reliability and stability.
- Added optional faster recording speeds, up to 10x.
- Added podcast recording support with native MP3, Ogg, FLAC and optional AAC audio.
- Improved handling of pauses, repeated songs and track changes.
- Improved automatic metadata, album artwork and synchronized lyrics updates.
- Added automatic retries when saved files are in use.
- Fixed automatic skipping of already downloaded songs.
- Improved detection of incomplete or corrupted recordings.
- Improved compatibility with newer Spotify versions; hooks attempt runtime discovery on unknown versions.
- Simplified logging and separated technical diagnostics.
- Reduced unnecessary processing and background overhead.
- Added optional Never Pause playback recovery through the INI and menu.
- Fixed missing podcast audio details and support for older MP3 source tags.
- Improved duplicate routing, including files without Spotify track IDs.
- Added opt-in raw stream dumps with correlated metadata and replay tests.

Installation options:

- **Always on:** put `version.dll` beside `Spotify.exe` and restart Spotify.
- **Launcher:** extract `Floggfy-v1.3-Launcher-Windows-x64.zip` beside Spotify and run `Floggfy.exe`.

Use one installation option. Keep your existing `SpotifyHistory.ini` when upgrading.
Faster capture is disabled by default; podcasts default on and Never Pause defaults hidden/off.
