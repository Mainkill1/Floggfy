Changes compared with **Floggfy 1.2.4**.

- More reliable recording when pausing, seeking, repeating songs or changing tracks.
- Better matching of recorded audio to the correct song, with stronger checks for incomplete recordings.
- Added podcast recording in the original audio format, enabled by default.
- Added optional faster recording speeds, up to 10x.
- Added **Never Pause**, an optional setting that resumes paused Spotify playback.
- Improved automatic updates for song details, album artwork and synchronized lyrics.
- Fixed duplicate-file placement and improved automatic skipping of already downloaded songs.
- Added retries when saved files are busy, and an **Unmatched** folder for complete recordings that cannot be identified.
- Improved compatibility with newer Spotify versions, including **Spotify 1.3.9** (tested with 1.3.9.2055).
- Clearer logs, optional stream dumps for troubleshooting, and less background processing.

**Install:** quit Spotify, then place `version.dll` beside `Spotify.exe`, or extract the Launcher ZIP there and run `Floggfy.exe`. Use one installation option and keep your existing `SpotifyHistory.ini`.

Faster recording and Never Pause are disabled by default.
