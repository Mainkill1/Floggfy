## Keep separate

- native/artwork_collector.js, call/start, distinguishes logical timeout from physical transport-slot lifetime. A never-settling native call must not permit unbounded additional calls. native/metadata_collector.js, automatic/requestState, likewise keeps per-kind attempts, grants, generation and physical concurrency; these are observable constraints. Their different protocols and result semantics do not warrant a common request engine.
- native/telemetry_producers.js, classify and the fetch/XHR/beacon/Cosmos wrappers, and native classification must agree across process and language boundaries. Keep the separate runtime implementations and verify them with shared URL cases. The wrappers have deliberately different return/failure shapes.
- native/marked_playlist_sort.js, clearNativeSort/load/restore, has version-specific synchronous selection differences, asynchronous cache commits, source replacement, and mandatory native sort cycles. Keep the ownership and cancellation checks even if their branch counts rank highly.
- native/marked_recording.cpp and native/recording_file.cpp serve different memory and integrity contracts. The bounded random-access catalog metadata reader should not be replaced wholesale by the full recording validator. Likewise keep native/media_session.cpp's bounded polling and timeout checks for WinRT and the distinct format validators in native/mp3_stream.cpp, native/ogg_history_core.cpp and native/metadata_update_core.cpp.
- No whole-file deletion recommended. File size or a public declaration without an obvious direct call is insufficient evidence for removal, particularly for callbacks, Windows binding entry points, platform-specific implementations and header-only templates.
